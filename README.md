# 🎮 Number Guessing Game (Python)

## 📌 About the Project
The Number Guessing Game is a simple and interactive Python project in which the computer randomly selects a number between 1 and 100, and the player has to guess it.

The game offers different difficulty levels, limited attempts, hints, and a scoring system to make it more interesting.

## ✨ Features
- 🎯 Random number generation between 1 and 100.
- 🎚️ Three difficulty levels:
  - Easy – 10 attempts
  - Medium – 7 attempts
  - Hard – 5 attempts
- 📉 Score decreases with every incorrect guess.
- 💡 Hints to identify whether the secret number is even or odd.
- 🏆 High score tracking during the game.
- 🔄 Option to play again.
- ⚠️ Input validation to handle invalid entries.
- 🎉 Displays the correct number if the player runs out of attempts.

## 🛠️ Technologies Used
- Python
- Random Module

## ▶️ How to Run

1. Clone this repository.
2. Open the project folder.
3. Run the Python file:

```bash
python Number-Guessing-Game.py
```

## 🎮 How to Play
1. Start the game.
2. Select your preferred difficulty level.
3. Guess a number between 1 and 100.
4. Follow the hints to find the correct number.
5. Try to guess the number before running out of attempts.
6. Check your score and high score.
7. Choose whether to play again.
